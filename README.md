Descripción general 
    Este es un trabajo interactivo que simula un Cajero Automático desarrollado en Python. 

    El sistema está diseñado en mudulos, dividiendo las responsabilidades en (`main.py`, `logica.py`, `validaciones.py`) para mantener un código limpio, estructurado y fácil de mantener.

    Cuenta con un archivo para corroborar los usuarios y datos(`usuarios.txt`). Las funcionalidades principales son:
    * Inicio de sesión validando usuario y contraseña con nuestro archivo.
    * Consulta de saldo actual.
    * Ingreso de dinero (Depósitos).
    * Extracción de dinero.
    * Transferencias de dinero a otros usuarios registrados en el sistema o a terceros.
    * Actualización automática de los saldos en el archivo `.txt` tras cada transacción aprobada.

Instrucciones de ejecución
    Para probar el simulador en tu computadora, sigue estos pasos:

    1. Descarga o clonar este repositorio (Es importante tener todos los archivos en la misma carpeta). 
    2.  Abrir la carpeta del trabajo en un editor de codigo.
    3. Abrir una terminal dentro de esa misma carpeta.
    4. Ejecutar el archivo pricipal ingresando el siguiente comando en la terminal: python main.py
